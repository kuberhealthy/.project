# Security Policy

## Reporting Security Issues

The Kuberhealthy maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/kuberhealthy/kuberhealthy/security/advisories/new) form.

For more details, see the [Kuberhealthy security policy](https://github.com/kuberhealthy/kuberhealthy/blob/main/SECURITY.md).
